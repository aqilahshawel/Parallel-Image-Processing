 Parallel Image Processing

This repository implements a small image-processing pipeline to compare different execution paradigms in Python:

- Sequential (single-threaded)
- Thread-based parallelism using `concurrent.futures.ThreadPoolExecutor`
- Process-based parallelism using `concurrent.futures.ProcessPoolExecutor`
- Process-based parallelism using the `multiprocessing` module

The pipeline applies the same series of operations to each image:

1. Grayscale conversion
2. Gaussian blur (3x3 kernel)
3. Edge detection using Sobel filters
4. Image sharpening (weighted combination)
5. Brightness adjustment

The goal is to compare performance (execution time and scalability) across these approaches on the same workload.

---

## Repository Structure

- [sequential.py](sequential.py) – Baseline sequential image-processing pipeline.
- [cf_thread.py](cf_thread.py) – Parallel pipeline using `ThreadPoolExecutor`.
- [cf_process.py](cf_process.py) – Parallel pipeline using `ProcessPoolExecutor`.
- [mp_paradigm.py](mp_paradigm.py) – Parallel pipeline using `multiprocessing.Pool`.
- [food-101/](food-101/) – Input images (subset of the Food-101 dataset: pizza, sushi, hamburger, samosa).
- `food-101_processed_*` – Output folders generated by the different scripts.
- [.gitignore](.gitignore) – Ignores large data, caches, virtual environment, and logs.

## Dataset Setup

Place images in the following structure (only a subset of Food-101 is required):

```text
food-101/
	pizza/
		image1.jpg
		image2.jpg
		...
	sushi/
	hamburger/
	samosa/
```

Each script will create a corresponding processed output directory (for example `food-101_processed_sequential`, `food-101_processed_concurrent_futures_thread`, etc.).

## How to Run

All scripts share a similar interface. Run them from the project root directory.

### 1. Sequential (Baseline)

```bash
python sequential.py --limit 100
```

Arguments:

- `--limit` – Maximum number of images per category to process (default: 1000).

### 2. Thread-based Parallelism (concurrent.futures.ThreadPoolExecutor)

```bash
python cf_thread.py --workers 8 --limit 100
```

Arguments:

- `--workers` – Number of worker threads (0 = `CPU cores * 2`, minimum 2).
- `--limit` – Maximum number of images per category.

### 3. Process-based Parallelism (concurrent.futures.ProcessPoolExecutor)

```bash
python cf_process.py --workers 4 --limit 100
```

Arguments:

- `--workers` – Number of worker processes (0 = number of CPU cores, minimum 2).
- `--limit` – Maximum number of images per category.

### 4. Multiprocessing Pool (multiprocessing.Pool)

```bash
python mp_paradigm.py --workers 4 --limit 100
```

Arguments:

- `--workers` – Number of worker processes (0 = number of CPU cores, minimum 2).
- `--limit` – Maximum number of images per category.
